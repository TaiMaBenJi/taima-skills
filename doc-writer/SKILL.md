# 文档交付（Doc Writer）

## 一、产出位置

- 文档统一写到 `workspace/`（持久目录），文件名：`<主题>-<日期>.md`。
- 面向用户的成品：写完回报**绝对路径**，并附一句话摘要。

## 二、标准结构

```markdown
# <标题>（<日期>）

## 摘要
- 3 行以内说清结论。

## 正文
（按小节组织；数据、命令、证据分块）

## 附：执行记录
- 关键命令与输出摘要（可核验）
```

## 三、写作纪律

- **先结论后细节**；每个数字给来源或命令。
- 代码/命令一律用代码块，方便直接复制。
- 长文档分段写：先写骨架，再逐节补全（避免一次输出过长被截断）。
- 中文排版：中英文之间留空格；列表不超过两级。

## 四、交付示例

```sh
ls -la workspace/
# 回报：已生成 workspace/报告-2026-09-26.md（12KB），摘要：……
```
